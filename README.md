# 화장실나우 정책 페이지

화장실나우 앱의 공개 홈페이지 · 개인정보처리방침 · 이용약관입니다. (GitHub Pages로 게시)

- 홈페이지: https://cleanpass-toliet.github.io/toiletnow-policy/
- 개인정보처리방침: https://cleanpass-toliet.github.io/toiletnow-policy/privacy.html
- 이용약관: https://cleanpass-toliet.github.io/toiletnow-policy/terms.html

## 수정 방법

이 저장소의 HTML을 직접 고치지 마세요. 원본은 앱 저장소(TolietNow)의 `src/data.ts`입니다.

1. TolietNow에서 `src/data.ts`의 문구 수정
2. TolietNow에서 `npm run build:policy` 실행 → `docs/` 폴더에 HTML 생성
3. 생성된 `docs/` 안의 파일을 이 저장소에 복사해서 커밋 · 푸시
